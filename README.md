# Brainrot Runner

Мобільний 3D-раннер для Android: персонаж автоматично біжить уперед трьома смугами,
гравець свайпами уникає перешкод, збирає монети й проходить біоми.

Гра зібрана й грабельна: є моделі героїв з анімаціями, три біоми з власними дорогами
та перешкодами, меню з вибором героя й локації, музика, місії та магазин.

**Unity 6000.3.27f1 (6.3 LTS)** · URP 17.3 · Input System 1.20.1 · C# · Android (portrait, IL2CPP, ARM64, minSdk 24)

## Керування

| Жест | Дія |
|---|---|
| Свайп вліво / вправо | Зміна смуги |
| Свайп угору | Стрибок |
| Свайп униз | Підкат, у повітрі — швидке приземлення |
| Дотик по екрану | Пауза, перезапуск, навігація в меню |

У редакторі: стрілки або A / W / S / D, пробіл — стрибок, цифри 1 / 2 / 3 — перемикання біому.

## Що є в грі

**Геймплей**
- Автоматичний біг із поступовим прискоренням, три смуги з чергою команд
- Стрибок і підкат із власною гравітацією та зміною колайдера
- Три типи перешкод: обійти, перестрибнути, підкотитися
- Нескінченна траса з чанків: після старту жодного `Instantiate`
- Безпечний маршрут гарантується генератором — вільна смуга переходить лише на сусідню
- Монети ланцюжком ведуть від старої вільної смуги до нової, підказуючи траєкторію
- Зіткнення з причиною програшу текстом, перезапуск без перезавантаження сцени
- Воскресіння після програшу та пауза

**Контент**
- 10 героїв із моделями та анімаціями, вибір зберігається між запусками
- 3 біоми: City, Tundra, Savanna — власні дороги, перешкоди, оточення й колір неба
- Портал переходу між біомами
- Музика меню й забігу, звуки кліків, рівня та програшу

**Інтерфейс**
- Заставка, головний хаб, вибір біому, гардероб героїв, місії, магазин
- HUD: очки, монети, прогрес, пауза, прив'язка до `Screen.safeArea`
- Меню будується з редактора: **Brainrot → Збудувати гарне мобільне UI-меню**

## Що лишилось

- Плейтест з іншим гравцем без пояснення керування
- Решта біомів до десяти за повною концепцією
- Баланс складності: пороги очок, темп прискорення, щільність перешкод

## Запуск

1. Відкрити проєкт в Unity Hub.
2. Відкрити `Assets/brainrotrunner/Scenes/Prototype.unity` і натиснути Play.

Збірка APK: **Brainrot → Build Android APK (Release)**.
Налаштування платформи застосовує **Brainrot → Setup → 1. Apply Android Settings**.

## Структура

```
Assets/brainrotrunner/
  Config/      GameTuning, TrackPalette — числові параметри, матеріали, біоми
  Materials/   матеріали траси й перешкод
  Models/      моделі героїв, перешкод і оточення
  Scenes/      Prototype.unity
  Scripts/
    Core/         GameManager, GameTuning, GameState, Bootstrap
    Input/        SwipeDetector
    Player/       PlayerMotor, PlayerController, PlayerCollisionProbe,
                  LaneTracker, HeroSwitcher
    Camera/       FollowCamera
    World/        ChunkSpawner, TrackChunk, Obstacle, Coin, BiomePortal, TrackPalette
    Progression/  ScoreSystem, CoinSystem
    UI/           HeroSelectUI, HudView, GameOverView, SafeAreaFitter,
                  BrainrotAudioManager, BrainrotGameplaySystems
    Debug/        TuningOverlay
  Editor/      BrainrotSetup, BrainrotUIBuilder
```

Траса, HUD і меню будуються кодом, тому сцена лишається легкою, а `.unity`
не доводиться мерджити вручну.

## Продуктивність

Заміри на Samsung Galaxy A80 зроблені на ранній grey-box збірці, до додавання моделей
і біомів: 59.8 FPS за даними `SurfaceFlinger`, найгірший кадр 17.10 мс, 15 перезапусків
підряд без падіння. Поточну збірку з артом на пристрої ще не заміряно.
