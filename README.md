# Brainrot Runner

Мобільний 3D-раннер для Android: персонаж біжить уперед трьома смугами, гравець
свайпами уникає перешкод і збирає монети.

Поточна збірка — grey-box прототип: увесь візуал на примітивах Unity і flat-матеріалах,
без текстур, моделей і анімацій. Перевіряються керування, камера та відчуття гри.

**Unity 6000.3.27f1 (6.3 LTS)** · URP 17.3 · Input System 1.20.1 · C# · Android (portrait, IL2CPP, ARM64, minSdk 24)

## Керування

| Жест | Дія |
|---|---|
| Свайп вліво / вправо | Зміна смуги |
| Свайп угору | Стрибок |
| Свайп униз | Ковзання |
| Дотик по екрану | Перезапуск після програшу |

У редакторі працюють стрілки та A / W / S / D.

## Що вже зроблено

- [x] Автоматичний біг трьома смугами, плавна зміна смуги
- [x] Розпізнавання свайпів із порогом у сантиметрах екрана, а не в пікселях
- [x] Стрибок і ковзання з власною гравітацією, блокування конфліктних команд
- [x] Follow-камера, що не смикається при зміні смуги й не підкидає кадр у стрибку
- [x] Нескінченна траса з чанків із рециклінгом, без Instantiate після старту
- [x] Три типи перешкод: обійти, перестрибнути, підкотитися
- [x] Генерація завжди лишає щонайменше одну вільну смугу в ряду
- [x] Монети ланцюжком у вільній смузі як підказка маршруту
- [x] Зіткнення, екран програшу з причиною, перезапуск без перезавантаження сцени
- [x] HUD: очки, монети, прогрес, пауза, прив'язка до safe area
- [x] Android-збірка: 59.8 FPS на Galaxy A80, 15 рестартів підряд без падіння

## Що планується до готового MVP

**Текстури та матеріали**
- Текстури дороги, перешкод і оточення замість flat-кольорів
- Скайбокси під біоми

**Моделі та анімації**
- Риг і модель персонажа замість капсули
- Анімації бігу, стрибка, ковзання та падіння
- Система скінів: спільний силует і спільні анімації, змінюються голова, торс, аксесуари

**Меню**
- Стартове меню
- Вибір скіна бігуна та персонажа-переслідувача
- Вибір локації
- Збереження вибору між запусками

Повна концепція гри передбачає 10 біомів, портали між рівнями та автоматичну зміну
скіна при переході — це наступний крок після MVP.

## Запуск

1. Відкрити проєкт в Unity Hub.
2. Меню **Brainrot → Setup → 0. Run All Steps** — застосує налаштування Android,
   створить конфіги й згенерує сцену `Assets/brainrotrunner/Scenes/Prototype.unity`.
3. Відкрити сцену, натиснути Play.

Збірка APK: **Brainrot → Build Android APK (Release)**.

## Структура

```
Assets/brainrotrunner/
  Config/      GameTuning, TrackPalette — усі числові параметри та матеріали
  Materials/   flat-матеріали URP Lit, без текстур
  Scenes/      Prototype.unity — генерується скриптом
  Scripts/
    Core/         GameManager, GameTuning, GameState, Bootstrap
    Input/        SwipeDetector
    Player/       PlayerMotor, PlayerController, LaneTracker, PlayerCollisionProbe
    Camera/       FollowCamera
    World/        ChunkSpawner, TrackChunk, Obstacle, Coin, TrackPalette
    Progression/  ScoreSystem, CoinSystem
    UI/           HudView, GameOverView, SafeAreaFitter
    Debug/        TuningOverlay
  Editor/      BrainrotSetup — меню Brainrot
```

Сцена і траса будуються кодом, тому blockout відтворюється однією командою,
а `.unity` не доводиться мерджити вручну.
